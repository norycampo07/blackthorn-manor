====================================================
COMBAT DIALOGUE THRESHOLD FIX
====================================================

Current Issue

If an enemy loses multiple health thresholds quickly, especially when weakness items are used, threshold dialogue can be skipped and later appear on the defeat screen.

This creates awkward dialogue sequences.

====================================================

DESIRED BEHAVIOR

50% dialogue:
Combat only.

25% dialogue:
Combat only.

Defeat dialogue:
Defeat screen only.

====================================================

If an enemy dies before threshold dialogue is shown:

- Skip the missed threshold dialogue.
- Do not queue it.
- Do not replay it.
- Do not display it on the defeat screen.

====================================================

DESIGN GOAL

Fast victories reveal less dialogue.

Longer battles reveal more story.

Only defeat dialogue should appear after victory.

====================================================
LUCK AND FEAR ANIMATION ORDER
====================================================

If a Luck event causes Fear:

Animation sequence MUST be:

1. Coin Flip Animation

2. Fear Candle Animation

3. Luck Result Window

4. Player clicks Continue

5. Return to gameplay

The coin flip animation and Fear animation must never overlap.

The coin flip must fully complete before the Fear animation begins.

The Fear animation must fully complete before the Luck Result Window appears.

====================================================
COMBAT DAMAGE FEEDBACK
====================================================

OBJECTIVE

Make damage easier to notice while preserving atmosphere.

====================================================

ENEMY TAKES DAMAGE

When an enemy loses stamina:

- Briefly shudder the enemy portrait.
- Duration approximately 100-150ms.
- Keep the movement subtle.

Display:

-1 STAMINA

or

-2 STAMINA

near the enemy stamina bar.

The damage value should briefly appear and fade away.

Optional:

Apply a subtle dark-red tint flash.

Avoid excessive flashing.

====================================================

PLAYER TAKES DAMAGE

When the player loses stamina:

- Briefly pulse the stamina bar.
- Briefly highlight the updated stamina value.
- Use a subtle amber or muted-red glow.

Optional:

Apply a gentle scale pulse to the player status area:

98% → 100%

Avoid:

- Blood effects
- Full-screen flashes
- Heavy screen shake
- Eye-straining visual effects
