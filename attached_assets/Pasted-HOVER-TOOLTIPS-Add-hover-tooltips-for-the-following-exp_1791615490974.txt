IMPLEMENTATION
====================================================

Display tooltips when the player hovers over:

- Action buttons
- Character stats
- Fear gauge
- House Score gauge

Tooltips should appear immediately on hover.

Tooltips should disappear when the cursor leaves the element.

Tooltips should not block gameplay elements or buttons.
