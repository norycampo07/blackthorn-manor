BLACKTHORN MANOR
INVESTIGATION SYSTEM V1 TEST

GOAL

Implement the first complete Investigation Layer using the uploaded asset:

investigate-library-desk.png

Treat this as the reference implementation for all future investigation scenes in Blackthorn Manor.

Do not build a prototype.
Build the complete gameplay loop.

==================================================
LIBRARY INTEGRATION
==================================================

Room:
Library

Add a new room action:

Inspect Desk

Selecting this action launches the investigation layer.

==================================================
INVESTIGATION LAYER
==================================================

Investigation scenes are NOT:

- room transitions
- popup windows
- separate pages
- modal dialogs

Investigation scenes ARE:

A focused interaction layer placed over the current room.

When "Inspect Desk" is selected:

1. Keep the player in the Library.

2. Apply a semi-transparent dark overlay over the ENTIRE gameplay screen.

This includes:

- room illustration
- room title
- room description
- action buttons
- inventory UI
- journal UI
- status UI
- all gameplay elements

The purpose is to visually push the current UI into the background while maintaining awareness of the room.

3. Display the uploaded investigation asset:

investigate-library-desk.png

centered on screen.

The asset already contains transparency.

Do not generate a background.

Do not place it inside a frame.

Do not place it inside a window.

Do not create a popup.

The player should feel:

"I am still in the Library."
followed by:
"I am examining the desk more closely."

==================================================
NAVIGATION
==================================================

Display a small subtle control in the upper-left corner:

← Step Back

Requirements:

- understated
- elegant
- gothic styling
- small but discoverable
- not visually dominant

Clicking:

← Step Back

returns the player to normal Library view.

ESC key should perform the same action.

Do NOT use:

- Continue
- Exit
- Close
- Cancel
- X Button

The feeling should be:

Stepping away from the desk.

==================================================
HOTSPOT SYSTEM
==================================================

Implement coordinate-based hotspots.

Each hotspot supports:

- hover tooltip
- click interaction
- state persistence
- optional item rewards
- optional lore rewards

Hotspots should visually highlight subtly on hover.

Use:

- faint gold glow
- Victorian styling

No large modern indicators.

==================================================

==================================================

While the investigation layer is active:

Disable interaction with:

- room actions
- inventory buttons
- room navigation
- other gameplay controls

Allow interaction only with:

- investigation hotspots
- ← Step Back
- ESC

==================================================
DESIGN PHILOSOPHY
==================================================

Room Art = Atmosphere

Investigation Assets = Interaction

The room tells the player:

"Where am I?"

The investigation asset tells the player:

"What happened here?"

The entire experience should feel like physically leaning closer to an object inside Blackthorn Manor rather than opening a separate interface.
